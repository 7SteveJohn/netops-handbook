## 它是什么

**脉络 · NetCraft**（原名 NetOps Handbook）是一个为零基础学习者与一线网络/系统运维工程师打造的 **Android 原生离线网络工程与运维随身手册 App**，采用全新 **Jetpack Compose + 液态玻璃（Liquid Glass）** 光学交互设计。

所有内容——**50 章 120 万字运维教材全书**、知识模块、排障案例、五平台命令字典、面试题库、CLI 模拟器、22 张内置横竖屏成对壁纸——全部离线封装在安装包内，装机即用，机房断网也能秒查。

适合这些场景：

- 🏗 机房割接现场，没网也能秒查多厂商命令与排障步骤
- 📘 通勤与自习时系统精读 50 章网络与 Linux 运维讲义，断点续读
- 📝 面试突击复习，随时翻阅 STAR 话术拆解与 199 道自测题
- 📖 上课学网络时当随身字典，全局秒搜协议原理、命令与教材段落
- 🔧 现场排障速查，对照「现象 → 根因 → 排查命令」快速定位故障

不适合：指望只翻它就把网络学会。系统掌握工程能力还得靠真机实验与现场实践。

## 核心板块

### 📘 运维教材全书 — 12 领域 · 50 章 · 约 120 万字

体系化覆盖从底层通信原理到云原生 SRE 的完整工程讲义，离线随包秒开：

- **12 大技术领域、50 章深度正文**（1,003 个二级小节、25,059 个结构化内容块）：涵盖网络基础与协议、园区网与无线、路由与数据中心（OSPF/IS-IS/BGP/VXLAN/EVPN）、广域网与 VPN、安全与 QoS、虚拟化与 Kubernetes 容器网络、Linux 服务器与数据库运维（8 章）、监控与自动化运维、备份容灾与割接管理、机房综合布线、端到端排障方法论及跨厂商命令矩阵

- **全书毫秒级检索**：内置中文 2-gram + 拉丁词倒排索引，右上角全局搜索输入任意协议或命令，一键空降对应章节段落

### 📚 学习 — 89 个知识模块

按四阶段组织的速查与带练卡片路径：

1. **零基础入门与基础设施**（18 模块）— OSI/TCP 分层、IPv4/掩码与网关、ARP、ICMP 与 ping/tracert、TCP/UDP、DHCP、DNS、NTP、抓包（tcpdump/Wireshark）、iperf3、Windows 分层排障、华为 VRP 视图与开局实验

3. **广域网、安全、无线与 NetDevOps**（22 模块）— NAT / PPPoE / MPLS L3VPN / SD-WAN、ACL 与防火墙 Zone、IPsec / SSL VPN / MACsec、802.1X 准入、无线 AC-AP 与 802.11r 漫游、Netmiko / Ansible / GitOps

```

  Cisco: switchport trunk allowed vlan 10
  中兴: port trunk permit vlan 10
  Linux: bridge vlan add vid 10 dev eth0
```

## 使用方式

1. **下载安装** → 前往 [Releases 页面](https://github.com/7SteveJohn/netops-handbook/releases/tag/v2.1.0) 下载正式签名包 `NetCraft-v2.1.0.apk`，直接安装即可（旧版 NetOps 用户可直接覆盖安装升级，进度与收藏完整保留）
2. **打开即用** → 底部四个 Tab 切换：**学习 / 排障 / 字典 / 我的**；首页首屏可直接进入 **「运维教材全书」**
3. **全局检索** → 右上角灵动水滴胶囊点 🔍 秒搜全站知识卡、命令与 120 万字教材段落
4. **明暗切换** → 右上角双格胶囊点 ☀️ / 🌙（或横滑水珠）实时切换深浅色主题
5. **侧滑目录** → 左上角 ☰ 呼出空间毛玻璃抽屉快速跳转任意阶段与工具

> **隐私说明**：本应用**不申请任何系统权限**——无联网权限、无存储权限、无广告 SDK、无后台服务。首次安装时系统提示「未知来源」属正常现象，确认安装即可。

## 技术架构

- **Jetpack Compose 全原生 UI + AGSL 实时光学着色器**：顶栏、悬浮胶囊/贴底双态底栏、侧边抽屉与全部 13 个功能页面均由原生 Compose 驱动；壳层采用 `LayerBackdrop` 同帧采样与凸透镜色散折射着色器，滚动列表微组件采用单遍 `drawWithCache` 零离屏缓冲架构保障 120Hz 满帧顺滑
- **高性能离线检索引擎**：120 万字教材采用后台 IO 预热 + 原始整型数组倒排索引（检索延迟 `< 0.3ms`），章节正文采用异步流式预解析与 LRU 缓存
- **五道自动化构建门禁**：离线零外链门禁、玻璃覆盖门禁、内容与统计一致性门禁、44 组壁纸明暗 WCAG 对比度门禁、JS-Native 桥面零死桥门禁
- **开源协议**：仅供学习交流 · 禁止商用（见 [LICENSE](./LICENSE)）

### v2.0.5 · 返回键稳态 + 搜索交互收拢 + 构建水印

> 本轮核心：Android 返回链路三处竞态/错挂修复、搜索栏 ✕ 退场与搜索态三路收拢、
> 装机构建水印、smoke 回归扩至 95 条全绿。

**返回键稳态（Android 壳）**
- `enableOnBackInvokedCallback` 此前误挂在 `<activity>` 上被系统整体忽略，App 一直跑旧版返回派发；现挂到 `<application>`，Android 13+ 走系统统一派发，返回行为不变。
- 修「第一次打开就弹退出提示、之后确认机制消失」：冷启动网页未就绪时 500ms 超时按根页面处理，连按两下被误判成确认退出；现在应答窗口内的连按直接忽略。
- 二次返回退出改走 `finishAndRemoveTask`：不再依赖 androidx 兜底回退链，残留任务不会再让下次进入的退出确认错乱。
- 渲染进程被回收重建时，先按契约回掉挂起的文件选择器（恰好一次 null），选择结果不再喂给已销毁的 WebView；载入重试守卫捕获失败实例本身，防止过期重试命中新实例。
- 导出写盘、图片解码压缩等重 I/O 移到专用后台线程，主线程只留 Toast。

**搜索：叉号退场，状态不残留**
- 清空 ✕ 整体移除（三轮反馈定论：叉号一律会被误读为「关闭搜索」）。清空 = 退格键，清到空 = 退出搜索；退出 = 框外「取消」；桌面 Chrome 原生 ✕ 一并隐藏。
- 搜索态三路收拢：切 tab、同 tab 二次点击、点结果进内容，搜索栏都自动收起。
- 返回键先收搜索再走正常回退；收起态的搜索路由条目（僵尸页）被跳过，返回落点必是真实页面。
- 连续打卡断签归零：最后打卡既不是今天也不是昨天时显示 0（此前一直挂旧数字）。
- 打卡后抽屉分组计数即时刷新；移除「左滑呼出目录」残留提示（该手势 v2.0.4 已删，提示在教一个不存在的手势）。

  展开后底部给「上一张 / 下一张」，跨阶段时把目标阶段名一起标出（如「园区核心 · VLAN 接入类型」）。

- 冒烟测试补上排障/面试/字典三类视图的逐卡展开：新增卡片此前只测阶段页，等于没测 —— 现在共 133 张卡逐张展开、零异常。

**平板与大屏（纯 CSS，前后都用同源 iframe 按真实媒体查询量过）**
- 标题栏与正文列对齐：≥900 时正文已到 860，标题栏仍停在 720，左边缘差 70px；现在两者同为 860、左边 210 一致。

  tab 在格子里原本贴左，导致整组中心比视口中心偏左 56px，现在显式居中（1280 下 640 = 视口中心）。
- 中文正文行长压进可读区：宽屏下 `.note`/列表项限 42em（约 42 字/行，此前 828px ≈ 55 字/行），
  终端块与拓扑图保持满宽（792px / 772px）—— 可读性与代码可读性各取所需。
- 断点从 640 下调到 600：8" 平板竖屏与分屏常落在 600dp，此前整档跳到无上限布局，620–640 区间还会跳观感。
- 手机档回归：390×844 下页面、标题栏、胶囊、正文宽度与改动前一致，六个视口均无横向溢出。
- ≥1200 大横屏/桌面/DeX 改两栏卡片流：此前只有一列 860，1600 宽时两侧各空 370px。实测 1600×1200 下
  阶段页 13 张卡排成两列（列宽 568），展开的那张由 JS 打 `is-wide` 占满整行（终端块拿到 1112px 而非半列），
  排障页与面试页同样两栏；1024/800/390 仍是单列，六个视口均无横向溢出。
  没有依赖 `:has()` —— 老 WebView 不支持会静默降级，所以用一行 JS 标记。

**质感：把液态玻璃真的做成玻璃，并给文字设可读性下限**
- 先修一个「名存实亡」：降级判定以前是「UA 里有 wv 就全降」，把现代 WebView 一并打回平涂白板，
  而 liquid 模式又自己把 blur 设成 0（注释写"通透设计"）—— 真机上既没有模糊也没有高光。
  现在按能力探测降级（`CSS.supports('backdrop-filter')` + Chromium 版本下限），liquid 给回 18px 模糊。
- 模糊改成**单层预模糊背景**（`.wall`：壁纸铺一次、blur 一次，再 saturate 180% 与按主题压暗），
  滚动内容只叠半透明薄板、不再逐元素读 backdrop。逐元素 `backdrop-filter` 正是当初「滚动白雾闪」的根因，
  成本还随卡片数线性增长；`feDisplacementMap` 那套真折射在滚动界面上过不了 16ms/帧，没做。
- 实测出来的缺陷比"看着不美"严重：三级文字 `#86868b` 在 14 张内置壁纸上 **100% 面积低于 WCAG AA 的 4.5:1**，
  最差 1.00:1（等于隐形）；把它拉到纯白底上也只有 3.6:1 —— 这个 token 本来就够不到 AA。
  现在玻璃作用域内二/三级文字改 `#3c3c40`/`#55555a`（暗色 `#e6e6ea`/`#b9b9c2`），并按当前壁纸的亮度带
  **自动算出玻璃板不透明度下限**（明暗两套，0.46–0.92），通透度滑块拉到低于下限即被兜住。
- 最紧的一组（最亮壁纸 + 深色 + 通透度拉到底）真实引擎实测：说明文字 4.63:1、二级文字 7.25:1；
  修复前同一处是 1.00:1、且 100% 面积不达标。
- 新增「增强对比度」开关（四家厂商都有这一档）：目标从 AA 的 4.5:1 抬到长时间阅读的 7:1。
  只加厚玻璃到不了 7:1 —— 实测暗色下把 alpha 顶到 0.96 也只有 5.6:1，天花板是玻璃板自身的亮度；
  所以这一档同时换上更强对比的文字 token（浅色 `#2c2c30`、深色 `#e6e6ea`），必要时才再加厚。
  同一组最紧配置实测 10.29:1 / 7.25:1。
- 按压形变引擎（"QQ弹弹、按住能拉扯"那一下）：按住即整体压缩 2.5%，跟手位移上限 7px 并**沿拖动方向拉伸、
   垂直轴反向压缩**（面积近似守恒，看着才像软体），松手用弹簧过冲回位。只碰 transform，走合成层不触发布局；
   浏览器一旦接管滚动就收 pointercancel 顺势回位，绝不和滚动抢。作用于 tab / 筹码 / 按钮 / 列表行 / 阶段卡 /
   统计块 / 卡头 / 回顶按钮。必须用 `!important`：入场动画的 `fill:both` 优先级在普通内联样式之上。
   「动画效果 = 关闭」、系统要求减少动态效果、以及降级/低电量设备都不启用。
- 手感只能真机调，所以配了**设备内实时调参面板**：长按「全局质感」弹窗标题 0.6 秒展开（隐藏入口，不占正式界面），
   五个参数（跟手位移上限 / 按下压缩 / 沿拖动方向拉伸 / 垂直轴压缩 / 回弹时长）拨一下当场生效，
   面板里带一块可按住拉扯的演示，底部实时打印当前 JSON。数值存 `netops2.sqtune`，因此自动进 JSON 备份，
   导入时按"只收数值字段"验形、越界由 `getSqt()` 夹紧。冒烟新增一条端到端用例覆盖整条链路。
- 分节标签（「我的收藏」「资源」这类）原来整行戴着玻璃板却是零内边距零圆角，在深色壁纸上就是一条硬边色带 ——
   板子收到标签本身（`.sec__t` 胶囊），分隔线移到板外并渐隐收尾。
- 新增第六道门禁 `tools/audit-contrast.js`：14 张壁纸 × 明暗 × 二/三级文字复算对比度，任一组 <4.5:1 构建失败；
  换图没重新采样会被 sha1 哨兵拦下，求解器的压暗系数与 `--bg-bri` 不一致也会失败。
- 借厂商做法里最便宜的两味：内缘 30px 扩散白光（"厚玻璃"的主要线索，不用额外图层）、
  提饱和必须同时压暗背后（只 `saturate` 就是业界口中的"难看的灰玻璃"）。

**稳定性**
- 修掉一个真会白屏的缺陷：启动路径上有 6 处直接读 localStorage 未做兜底，存储不可用（file:// 源、
  隐私模式、配额耗尽）时首帧就抛异常 —— 现在全部走带 try 的读写，并新增第五道构建门禁，
  源码里再出现未兜底的 `localStorage.` 调用直接构建失败
- 离线冒烟套件本身是坏的（在 jsdom 里用了 file:// 源，全红），修好后逐视图、逐拓扑、返回栈、
  CLI 与搜索共 47 项全通过；两条过期断言改为按真实数据比对
- 内存压力下降级：系统回收内存时收掉离屏预栅格化缓冲（视口大小量级，约 10 MB/页）并让 WebView
  释放缓存，回前台自动恢复，不再靠系统直接杀渲染进程
- 物理返回键的「再按一次退出」只保留原生一层（此前网页与原生各做一遍，同一键可能叠两个 Toast），
  并加 500ms 应答看门狗：网页卡死不再让返回键失灵；网页内手势仍走自己的确认逻辑
- 构建日志的体积口径改为字节：产物真实大小 529.8 KB（542530 字节；此前按字符数统计，中文按 3 字节被低估约 17%）
- 「动画效果」开关以前是**空的**：只往 `<html>` 写 `data-motion`，全站没有任何消费方 —— 界面显示"已关闭"，
  实际照旧动。现在 CSS 侧按 `prefers-reduced-motion` 同一套做法接上（用 .001ms 而不是 `animation:none`，
  后者会让带入场动画的元素停在 `opacity:0`，等于把"看不见字"又引进来一遍），JS 侧高光跟随与数字滚动一并停
- 相册自选壁纸重启后不再丢失（此前写完就被覆盖，只留下半透明内容层而没有底图，看着像一片白）
- 导入备份需二次确认，只接受已知键并逐项校验类型，导入前自动留一份可回滚快照
- 本地存储写不进去时明确提示，不再「以为存住了、重启才发现没了」
- 质感弹窗里的滑块绑定原来按 `.glass-slider` 类选元素，再取 `data-glass` 当键 —— 任何复用这套外观但不带该属性的
  新滑块都会让 `$('#glassVal_null')` 取到 null 并在拖动时抛异常（加调参滑块时真撞上了）。改为按
  `.glass-slider[data-glass]` 收窄并给标签写入加空值兜底。
- 冷启动不再把用户手动关掉的玻璃偷偷打开
- 主文档载入失败会有限次自动重试，仍失败给出可读的错误页（此前是永久白屏）
- WebView 渲染进程被系统回收后自动重建界面（此前继续调用已失效实例，必闪退）
- 切到后台暂停 WebView，不再在后台偷跑定时器与预栅格化
- 换机与云备份补上 `device-transfer`（此前是空模板，换机不带任何进度）
- 备份规则改走 `domain="root" path="."`：打包时 `lintVitalRelease` 判 fatal（exclude 不在任何 include 路径之内），
  顺出一个更实的问题——旧写法 `include domain="file" path="app_webview"` 命中不到东西。官方文档里 `file` 域 =
  `getFilesDir()`（即 `<数据目录>/files`），而 WebView 的私有目录在数据目录根下，`file` 域管不到它。
  一条 `root`（文档口径：存储属于此应用的所有不公开文件的目录）+ `.` 于是同时包住
  files / databases / shared_prefs 与 localStorage，也不必再赌子路径的确切拼写；
  `cache` / `no_backup` 显式排除（云端备份是每应用每用户 25 MB 上限）。
- 导出文件名净化，挡掉 `../` 与路径分隔符
- 读取相册图片改为「界内缩放 + 逐级降质压缩」，不再把 JPEG 从中间截断成坏图

**工程**
- 构建期新增三道门禁：零外链校验、玻璃覆盖门禁（不透明底色必须走 token 或登记例外理由）、
  内容一致性门禁（模块字段齐备、字典行形状、题库答案下标、README 每个数字与实际数据比对、
  被产品否决过的措辞不得回流、忘记跑 gen-data.js 直接报错）
- CLI 命令库条数改为构建期可复算（浏览器与 Node 共用同一份推导规则），不再「只有跑起来才知道」
- `06-anim.css` 里成对重复的规则清掉 107 条（408 → 301 条，CSS -11 KB）：只删「后面还有一份选择器与声明体
  都完全相同的存活副本」的早先副本。静态核对确认没有一条规则被删到不剩、也没有改写任何规则；再用真实引擎对
  7 个界面状态 × 114 个元素 × 20 个属性 ×（自身 / `::before` / `::after`）做计算样式快照，前后哈希零漂移。
  第一版删除脚本漏掉了收尾花括号，被构建的语法自检当场拦下 —— 那道自检就是为这种事存在的。

### v2.0.3 · 玻璃三模式 + 手势返回 + 退出确认

质感三模式终于统一了：

- **液态玻璃**：背景透明，看得到壁纸。通透度滑块（10-95%）联动所有内容组件——主卡、子段、列表、统计、阶段全模块响应，不再"只能看见底栏在变"。
- **毛玻璃（frosted）**：实色暖白磨砂 + 背景模糊跟随 px 滑块（8-20px）。朦胧感统一，不再"有时模糊有时色块"。
- **高斯模糊（gaussian）**：近不透明 + 轻模糊，省电档。和毛玻璃同套 px 滑块。
- **Android WebView 降级检测**：检测到 WebView 或低版本 Chrome 时，自动禁用 backdrop-filter 改用高 alpha 实色蒙版（0.85）——修复之前 Android 上"滚动白雾闪/色块/蒙版消失"。

手势与返回彻底打通：

- **左滑手势全页面生效**：二级菜单左滑=返回上一级，学习页根界面左滑=呼出目录。非学习模块左滑也响应。
- **退出二次确认**：根界面触发返回时弹 Toast「再按一次退出应用」，2 秒内再次才真正退出——物理返回键和网页手势行为一致。
- **NetOpsBack 统一 `handleBackOrExit`**：首次拦截返回 `true` 阻止原生退出，二次返回 `false` 才放行——之前原生返回键绕过确认直接退出的 bug 修复。
- **Home 回桌面重进修复**：boot() 防重复绑定、visibilitychange + focus 重置退出计时——之前回桌面重进后手势失效的问题根治。

内容与稳定性：

- **GPU 合成层提升排除 sheet/drawer/appbar/tabbar**（它们已有自己的 slide transform）——之前 GPU 提升覆盖 slide 动画导致 sheet/drawer 卡死的 bug 修复
- **壁纸下二级子段统一蒙版**（液体=透明 / 毛玻璃=高 alpha 实色 + 模糊 / 高斯=近不透明），不再"抠图"或"白雾闪"
- **截图中屏幕与壁纸**两套视觉语言统一

### v2.0.2 · 壁纸与个性化

加了 14 张内置壁纸，二次元、芙宁娜、今汐等各两张，可以直接选，也可以从相册自己挑。选了背景壁纸之后，卡片自动半透明，能透出壁纸来。

数据终于能备份了。我的页加了「导出数据备份」和「导入数据恢复」，进度、收藏、测验成绩打包成 JSON，换机能找回来。
