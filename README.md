## 它是什么

NetOps 2.0 是一个为零基础萌新做的 **Android 离线网络学习辅助 App**。

打开即用，不联网、不注册、不看广告。所有内容——68 个知识模块、35 个排障案例、58 条多厂商命令对照、53 道面试真题、431 条 CLI 模拟器命令、14 张内置壁纸——全部打包在安装包里，断网也能查。

适合这些场景：

- 🏗 机房割接现场，没网也能查命令
- 📝 面试突击复习，通勤路上刷题
- 📖 上课学网络时当随身字典，课前预习、课后查漏
- 🎯 对着教材和实验看路线图，知道自己在学哪一块
- 🔧 现场排障速查，秒找对应命令和思路

不适合：指望只翻它就把网络学会。系统学习还得靠教材、课程和真机练习。

## 五大功能

### 📚 学习 — 68 个知识模块

按阶段组织的学习路径，从 OSI 七层模型一路走到云原生 SRE：

1. **零基础入门与基础设施**（12 模块）— OSI/TCP 分层、IPv4/掩码与网关、ARP、ICMP 与 ping/tracert、TCP/UDP 与三次握手、DHCP、华为 VRP 视图与配置管理
2. **园区网核心与高可用**（11 模块）— 静态路由与最长匹配、VLAN / Trunk / SVI、STP / RSTP 端口角色、OSPF 多区域与 LSA、BGP 属性选路、MSTP / VRRP / iStack / Eth-Trunk
3. **广域网、安全与自动化**（17 模块）— NAT / PPPoE / MPLS L3VPN、ACL 与防火墙 Zone、IPsec、802.1X、无线 AC-AP 与 802.11r 漫游、Netmiko / Ansible / Git / GitOps
4. **云原生与 SRE**（26 模块）— VXLAN / EVPN、IPv6、BGP unnumbered（v4 走 v6 下一跳）、SNMP 与 gNMI/YANG 流式遥测、Prometheus / Syslog、K8s CNI / Calico / NetworkPolicy / Ingress 选型 / Gateway API / CoreDNS、eBPF、混沌工程、SLI / SLO / 错误预算

每个模块点进去就是完整的内容页，支持收藏和进度标记。

### 🔧 排障 — 35 个真实场景

典型故障的「现象 → 分析 → 命令」三段式卡片：

- 链路不通怎么排查？从物理层到路由逐层定位
- 隧道 MSS 导致大包丢包？`tcp adjust-mss` 一行搞定
- STP 风暴 / MAC 地址漂移 / OSPF 邻居起不来……每个都有对应的急救命令

### 📖 字典 — 58 条多厂商命令对照

同一功能，华为 / Cisco / 中兴 / Linux 四家命令并排显示：

```
示例：Trunk 放行 VLAN
  华为: port trunk allow-pass vlan 10
  Cisco: switchport trunk allowed vlan 10
  中兴: port trunk permit vlan 10
  Linux: -
```

还收录了高频巡检命令（BGP 邻居汇总、路由表查看、接口简要状态等）。

### 💻 CLI 终端模拟器 — 431 条命令

内置离线终端模拟器，贴近真实设备操作体验：

- **431 条命令**：华为 VRP / Cisco IOS / 中兴 / Linux / K8s 五平台
- **智能匹配**：精确匹配 → 前缀联想 → 模糊近似建议；输入 `display` 自动列出全部 `display` 开头的命令
- **分组帮助**：`help` 按平台/功能分组展示常用命令示例
- **历史持久化**：命令历史存本地，上下方向键翻看，重开 App 自动恢复
- **平台切换**：`mode hw|cs|zte|lx` 随时切换设备类型，提示符跟随变化

### 📝 面试 — 53 道真题

从概念题到架构设计题，覆盖各层次：

- 「Hybrid 接口和 Access / Trunk 的区别？」
- 「OSPF 的 LSA 类型有哪些？Type 7 是什么？」
- 「iptables 规则多了性能会怎样？是 O(n) 还是指数级？」
- 「公有云里 Calico 为什么不能直接跑 BGP？」

每道题带解析和 STAR 拆解（S/T/A/R 各说哪一句、落点在哪里），帮你在面试前快速过一遍关键知识点。

### 👤 我的 — 进度追踪与资源

- **总进度圆环**：已掌握 / 总项数百分比
- **分项统计**：知识模块、排障案例、面试真题各自完成度
- **收藏夹**：把常看的模块或命令一键收藏
- **模拟测验**：72 道选择题，随机抽 10 题、答完判分、记历史最佳与连击
- **错题本**：答错的题自动留下，每题带「回看这张卡」锚点，一键跳回对应模块并展开；再练时做对一次即自动移出错题本（本地持久化，重启不丢）
- **资源入口**：速查表（12 张高频对照表）、术语词典（48 条）、学习路线图
- **内置壁纸**：14 张精选壁纸（二次元 / 芙宁娜 / 今汐 / 卡提希娅 / 雷电将军 / 纳西妲 / 守岸人），或从相册自选，壁纸模式下内容层半透明
- **个性化质感**：液态玻璃（通透度 10-95% 可调）/ 标准毛玻璃 / 高斯模糊三种全局质感
- **数据备份**：进度 / 收藏 / 测验成绩一键导出 JSON，换机可导入恢复

## 使用方式

1. **下载安装** → [Releases 页面](https://github.com/7SteveJohn/netops-handbook/releases/tag/v2.0.5) 下载 `app-release.apk`，允许「未知来源」安装即可
2. **打开即用** → 底部五个 Tab 切换：**学习 / 排障 / 字典 / 面试 / 我的**
3. **搜索** → 右上角 🔍 图标全局搜索任意关键词
4. **深色模式** → 右上角 ☀️ 图标切换明暗主题
5. **左缘右滑** → 屏幕左缘向右滑即返回上一层（等同返回键，页面内横向滚动不受影响）
6. **返回导航** → Android 物理返回键逐层回退，到根页可退出

> **注意**：本应用**不申请任何权限**——没有网络，没有存储，没有震动。首次安装时系统可能提示「未知的开发者」，这是正常的安全提示，选择「仍然安装」即可。

### v2.0.5 · 返回键稳态 + 搜索交互收拢 + 构建水印

> 本轮核心：Android 返回链路三处竞态/错挂修复、搜索栏 ✕ 退场与搜索态三路收拢、
> 装机构建水印、smoke 回归扩至 95 条全绿。

**返回键稳态（Android 壳）**
- `enableOnBackInvokedCallback` 此前误挂在 `<activity>` 上被系统整体忽略，App 一直跑旧版返回派发；现挂到 `<application>`，Android 13+ 走系统统一派发，返回行为不变。
- 修「第一次打开就弹退出提示、之后确认机制消失」：冷启动网页未就绪时 500ms 超时按根页面处理，连按两下被误判成确认退出；现在应答窗口内的连按直接忽略。
- 二次返回退出改走 `finishAndRemoveTask`：不再依赖 androidx 兜底回退链，残留任务不会再让下次进入的退出确认错乱。
- 渲染进程被回收重建时，先按契约回掉挂起的文件选择器（恰好一次 null），选择结果不再喂给已销毁的 WebView；载入重试守卫捕获失败实例本身，防止过期重试命中新实例。
- 导出写盘、图片解码压缩等重 I/O 移到专用后台线程，主线程只留 Toast。

**搜索：叉号退场，状态不残留**
- 清空 ✕ 整体移除（三轮反馈定论：叉号一律会被误读为「关闭搜索」）。清空 = 退格键，清到空 = 退出搜索；退出 = 框外「取消」；桌面 Chrome 原生 ✕ 一并隐藏。
- 搜索态三路收拢：切 tab、同 tab 二次点击、点结果进内容，搜索栏都自动收起。
- 返回键先收搜索再走正常回退；收起态的搜索路由条目（僵尸页）被跳过，返回落点必是真实页面。
- 连续打卡断签归零：最后打卡既不是今天也不是昨天时显示 0（此前一直挂旧数字）。
- 打卡后抽屉分组计数即时刷新；移除「左滑呼出目录」残留提示（该手势 v2.0.4 已删，提示在教一个不存在的手势）。

**构建可核验**
- 「我的」页脚新增构建水印：装机一看便知跑的是哪一刻构建的包，旧 APK 与 devpage 顶替无所遁形。
- smoke 回归扩至 95 条全绿：返回键分支、搜索收拢三路、僵尸页跳穿、手势边界、断签归零、抽屉计数、错题本确认拦截。

**玻璃不再露白色色块**

- 修掉真机上进度圆环被实色蒙版压成实心白圆、弧线消失的问题。
- 弹窗保留 .55 的可读性下限：实测在暗色壁纸区域，正文对比度从 1.12:1 提到约 5.6:1（WCAG AA 需 4.5）。

**质感：把液态玻璃真的做成玻璃，并给文字设可读性下限**
- 先修一个「名存实亡」：降级判定以前是「UA 里有 wv 就全降」，把现代 WebView 一并打回平涂白板，
  而 liquid 模式又自己把 blur 设成 0（注释写"通透设计"）—— 真机上既没有模糊也没有高光。
  现在按能力探测降级（`CSS.supports('backdrop-filter')` + Chromium 版本下限），liquid 给回 18px 模糊。
- 模糊改成**单层预模糊背景**（`.wall`：壁纸铺一次、blur 一次，再 saturate 180% 与按主题压暗），
  滚动内容只叠半透明薄板、不再逐元素读 backdrop。逐元素 `backdrop-filter` 正是当初「滚动白雾闪」的根因，
  成本还随卡片数线性增长；`feDisplacementMap` 那套真折射在滚动界面上过不了 16ms/帧，没做。
- 实测出来的缺陷比"看着不美"严重：三级文字 `#86868b` 在 14 张内置壁纸上 **100% 面积低于 WCAG AA 的 4.5:1**，
  最差 1.00:1（等于隐形）；把它拉到纯白底上也只有 3.6:1 —— 这个 token 本来就够不到 AA。
  现在玻璃作用域内二/三级文字改 `#3c3c40`/`#55555a`（暗色 `#e6e6ea`/`#b9b9c2`），并按当前壁纸的亮度带
  **自动算出玻璃板不透明度下限**（明暗两套，0.46–0.92），通透度滑块拉到低于下限即被兜住。
- 最紧的一组（最亮壁纸 + 深色 + 通透度拉到底）真实引擎实测：说明文字 4.63:1、二级文字 7.25:1；
  修复前同一处是 1.00:1、且 100% 面积不达标。
- 新增「增强对比度」开关（四家厂商都有这一档）：目标从 AA 的 4.5:1 抬到长时间阅读的 7:1。
  只加厚玻璃到不了 7:1 —— 实测暗色下把 alpha 顶到 0.96 也只有 5.6:1，天花板是玻璃板自身的亮度；
  所以这一档同时换上更强对比的文字 token（浅色 `#2c2c30`、深色 `#e6e6ea`），必要时才再加厚。
  同一组最紧配置实测 10.29:1 / 7.25:1。
- 按压形变引擎（"QQ弹弹、按住能拉扯"那一下）：按住即整体压缩 2.5%，跟手位移上限 7px 并**沿拖动方向拉伸、
   垂直轴反向压缩**（面积近似守恒，看着才像软体），松手用弹簧过冲回位。只碰 transform，走合成层不触发布局；
   浏览器一旦接管滚动就收 pointercancel 顺势回位，绝不和滚动抢。作用于 tab / 筹码 / 按钮 / 列表行 / 阶段卡 /
   统计块 / 卡头 / 回顶按钮。必须用 `!important`：入场动画的 `fill:both` 优先级在普通内联样式之上。
   「动画效果 = 关闭」、系统要求减少动态效果、以及降级/低电量设备都不启用。
- 手感只能真机调，所以配了**设备内实时调参面板**：长按「全局质感」弹窗标题 0.6 秒展开（隐藏入口，不占正式界面），
   五个参数（跟手位移上限 / 按下压缩 / 沿拖动方向拉伸 / 垂直轴压缩 / 回弹时长）拨一下当场生效，

   导入时按"只收数值字段"验形、越界由 `getSqt()` 夹紧。冒烟新增一条端到端用例覆盖整条链路。
- 分节标签（「我的收藏」「资源」这类）原来整行戴着玻璃板却是零内边距零圆角，在深色壁纸上就是一条硬边色带 ——
   板子收到标签本身（`.sec__t` 胶囊），分隔线移到板外并渐隐收尾。

### v2.0.3 · 玻璃三模式 + 手势返回 + 退出确认

质感三模式终于统一了：

- **启动无闪白**：冷启动按上次主题着色
